# 나만의 영어공부

React + TypeScript + Vite로 만든 개인용 영어 단어 학습 웹 앱입니다. 별도의 서버 없이
브라우저 로컬 저장소(localStorage)에 학습 기록을 저장합니다.

## 주요 기능

- **플래시카드 학습**: 초급/중급/고급 단어를 카드 형태로 암기하고, Leitner 방식의
  간격 반복(SRS)으로 복습 스케줄을 관리합니다.
- **예문 학습**: 각 단어마다 영어 예문과 한글 해석을 함께 제공합니다.
- **학습 통계**: 연속 학습일(streak), 전체 정답률, 최근 7일 학습량, 레벨별 암기
  현황을 확인할 수 있습니다.
- **단어장 목록**: 전체 단어를 검색/필터링하고 단어별 암기 상태(새 단어 / 학습중 /
  복습 필요 / 암기 완료)를 확인할 수 있습니다.
- **발음 듣기(TTS)**: 브라우저 내장 Web Speech API로 단어/예문 발음을 들을 수 있습니다.
- **다크모드**: 시스템 설정/라이트/다크 중에서 선택할 수 있습니다.
- **AI 학습 도우미**: Google Gemini(`gemini-3.5-flash-lite`)를 이용해 단어에 대한
  추가 설명·유의어·예문을 생성하고, 영어 회화 연습 챗봇과 대화할 수 있습니다. API 키는
  사용자가 직접 입력하며 브라우저에만 저장되고 Google Gemini API로만 직접 전송됩니다.
- **영화 대본 어휘 세트**: `Before Sunrise (1995)` 대본에 자주 등장하는 표현을
  분석해 선별한 단어 225개가 포함되어 있습니다(뜻과 예문은 저작권 보호를 위해 대본을
  인용하지 않고 새로 작성했습니다). 단어장 페이지에서 "기본 단어장"과 구분해 필터링할
  수 있습니다.
- **내 텍스트로 읽기 연습(리더)**: 가지고 있는 대본이나 글을 붙여넣으면 단어를 탭해서
  뜻(단어장 매칭 또는 AI 설명)을 확인하며 읽을 수 있습니다. 붙여넣은 텍스트는 저작권
  보호를 위해 저장소에 포함되지 않고 사용자의 브라우저에만 저장됩니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 타입 체크 후 프로덕션 빌드
npm run lint     # oxlint 실행
```

## 기술 스택

- React 19 + TypeScript
- Vite
- 상태 관리: React Context + localStorage (외부 상태 관리 라이브러리 없음)
